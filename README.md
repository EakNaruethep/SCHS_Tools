# schs-tools

Interactive tools embedded (iframe) in articles on schomesquare.co.th.

- stahl-size/ : Stahl SVA-VE chemical anchor size slider (M8 to M30). Use ?ref=M12 to change the reference size.

- kingfisher-size/ : King Fisher KR Resin chemical anchor size slider (M10 to M24). Use ?size=M12 to change the starting size.
